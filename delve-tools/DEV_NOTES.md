# Delve — developer notes

## Repo
- Fork: https://github.com/tbradz/forge (upstream Card-Forge/forge). Our work lives on branch `delve`; `master` tracks upstream.
- Delve code: `forge-gui-mobile/src/forge/delve/` (keep new code here). Layouts: `forge-gui/res/adventure/common/ui/delve_*.json`; art in `ui/delve/` generated by `delve-tools/make_town_art.py` (building sprites cropped from Forge's `maps/tileset/buildings.png`).
- Upstream hooks (keep minimal): `StartScene.addDelveButton()`; `DuelScene.setOverride()` / `hasOverride()`, protected ctor, `matchBackground()`, `returnButtonLabel()`; `MatchScreen.getBG()` asks DuelScene for a custom background; `AdventureWinLose` uses `returnButtonLabel()`; `ViewWinLose` uses AdventureWinLose whenever a DuelScene override is active (needed for Commander-type games).

## Architecture
- `DelveHubScene` town (clickable building sprites; day/night art) → `DelveGateScene` (tier selector over unlocked tiers) → `DelvePackOpenScene` (prerelease: 6 boosters opened one at a time with shake/burst/fly-out/flip animation, rares glow; art from `delve-tools/make_pack_art.py`) → `DelveSealedScene` (Forge sealed `FDeckEditor`, in-memory controller, pool in Sideboard, free basics; closing with 40+ cards starts the run, fewer reopens) → `DelveMapScene` (map from `DelveMapGen`: fights, `?` events, merchants, rests, elite, boss) → `DelveDuelScene` (extends DuelScene; hosts Forge matches: 1v1 via `setup(...)`, Commander FFA via `setupCommander(deck, foes, decks, cb)`) → `DelvePickScene` (choose N of M cards; per-card button labels; view-only mode; one-shot extra button via `withExtra(label, action)`) → end of run: keep picks / Lock Deck / Vault → `DelveProfile`.
- Rules: run deck minimum 40; no free mid-run editing — thin via Merchant (sell) or Rest. Event damage never lethal. All gold numbers in `DelveEconomy`.
- Tiers (`DelveDay.tiers()`): every expansion/core set (150+ cards) released from 2003-07-01 on, oldest first. `DelveProfile.topTier()` = highest unlocked; clearing it (`clearTier`) unlocks the next. `DelveDay.forTier(day, tier)` = card world for a run (draft packs, rewards, enemy decks from the tier's set, with a 3-set era backup for thin colors; Commander decks use a 6-set window). `DelveDay.today()` = town world at the top tier.
- Map (`DelveMapGen`): one size, random 6-9 steps; elite at the midpoint (+1 more at 8-9 steps); boss last.
- End of run: clear = all gold found + 1 random token + one reward (3 boosters / 120 gold / pick 5 from run deck / Locked Deck). Defeat = gold x completion (steps done / total). Abandon = same as defeat but Insurance can't be used.
- Enemy deck tiers: FIGHT 18C/5U, ELITE 13/8/2, BOSS 9/9/5, CASTLE 8/10/5.
- Day cycle (`DelveProfile`): morning = one dungeon run; evening = one Castle event (1v1 bracket OR Commander pod); sleep at House → next day.
- IMPORTANT: DuelScene override must stay set until `exitDuelScene()` has been called; it's cleared in the afterTransition runnable.

## Features
- Run save/resume (`DelveRunSave`, stores day number). Character creation + hero walks the trail map.
- House: Sleep, Build a deck (Quest rules, collection only, `delve/decks/`), Build a Commander deck (Commander rules, collection only, `delve/commander/`), View collection, Change character. Shows token counts.
- Card Shop: daily singles + 2 booster types + Run tokens counter.
- Castle: 1v1 = 8-player single elim, best of 3. Commander pod = 4-player FFA, 40 life, own legal Commander deck or borrowed house deck; win 125g + booster + token. Entry 25g each.
- Run tokens (`DelveTokens`, `token.*` in profile.properties): Reroll 25g (draft pack or card reward), Treasure Map 90g (two clear rewards), Insurance 100g (a defeat pays like a clear, no unlock). Old Keepsake/Duplicate/Vault are refunded on load. Earned: every clear 1, Castle 1v1 champion / pod win 1.
- Tavern (`DelveTavernScene`, tavern.png, evenings only): 4 daily patrons from the top tier, unlimited 1v1 practice (ELITE decks) or Commander with 3 patrons; no fee, no prizes.

- Save slots (`DelveSaves`, `DelveSavesScene`): each save is `<userDir>/delve/saves/<name>/` (profile, collection, decks, commander, locked, run); `current.txt` remembers the last one; pre-slot data migrated into "Save 1". Title-screen Delve button opens the save menu.
- Boss perks (`DelvePerk`): one random perk per boss, scripted as custom cards `res/adventure/common/custom_cards/delve_perk_*.txt` (loaded by Adventure's Config.loadResources) placed in the boss's command zone via `RegisteredPlayer.addExtraCardsInCommandZone`; Rampant also starts with a basic land in play. Deploy must copy the perk .txt files too.
- Events: 22 in `DelveEvents` (results may return PICK_CARD / PICK_COPY / PICK_REMOVE sentinels). Special rooms TREASURE (pick 1 of 3 rares) and SHRINE (rare + next foe +6 life, or 5 life for 60 gold), ~12% each per event slot, max one each. `DelveRun.nextFoeLife` = blessing/curse on the next fight (saved).
- Map RNG compatibility: `DelveMapGen` keeps the original main-RNG call sequence (event pick replayed over the first 10 events) and rolls new things (special rooms, elite perks, the real event pick) on a separate `extra` RNG seeded from the run seed, so old saved runs rebuild the same map.
- Elite perks: `DelvePerk` entries with elite=true (Hardy, Sturdy, Fierce, Swift, Cunning), cards `delve_elite_*.txt`.
- Outfitter (`DelveOutfitterScene`, shardalley.png): 6 of Forge's skin sleeves for sale per day (40-120g), owned/current sleeve in profile (`sleeves.owned`, `sleeve.current`); applied via LobbyPlayer.setSleeveIndex in duels and RewardActor.setBackTexture (new upstream setter) in pack opening.
- Castle state saved to `<save>/castle.properties` + `castle.dck` at each step, restored on entering the Castle the same day.
- Dialogs: always build via `DelveDialogs` (make/body/listButton/gridButtons/wideButton/rowButtons) — gold title inside the frame; Adventure's createGenericDialog draws titles on the border. Disabled buttons dim via `DelveDialogs.dimWhenDisabled`.
- RewardActor.draw now resets the batch colour to white (upstream edit) so faded actors drawn before a card can't make it transparent.
- Pack opening has 'Open all' (`DelvePackOpenScene.openAll`).
- Deploy: device_commit_files caps at 100MB per call, so send the 6th jar part in a second call.
- Relics (`DelveRelic`, 11): run-scoped, saved in run.properties (`relics`, `startRelicChosen`, merchant offers in `merchantRelics`). Card relics = `delve_relic_*.txt` in the player's command zone; Vitality Charm (+5 max life, `run.maxLife()`), Iron Buckler (+4 life per fight, capped back to max after), Lucky Coin (+1 starting hand), Gold Idol (+50% fight gold) in code. Runs start with no relic (Tyler). Sources: elites (1 of 3, 50% rare), Treasure Room (1 of 2, 60% rare), merchant (60g / 90g rare).
- Difficulty curve: `DelveMapGen.scaleLife` + `depth()`: fights 12/15/17 life by third, decks Tier EARLY {21,2,0} / FIGHT {18,5,0} / LATE {15,7,1}; ELITE {12,8,3} 22 life; BOSS {7,9,7}, 30 life +tier/4 (max 40), perk + perk2 (elite perk). AI profile: Reckless for first-third fights, Default for everything else (overrides the user's Forge pref).
- New save flow: `DelveSavesScene.newSave` → `DelveCharacterScene` (character locked per save; no 'Change character') → `DelveIntroScene` (Bram the innkeeper, farmer.atlas, 7 pages, `introSeen` in profile; replay via Tavern 'Talk to Bram') → town.
- Card Shop bg: `ui/delve/shop_bg.png` (blurred/darkened market.png via make_pack_art.py).
- Audio (`DelveAudio`): Forge's Adventure playlists via SoundSystem.setBackgroundMusic — TOWN (hub, shop, outfitter, tavern, intro), CAVE (gate, pack opening, map), CASTLE, MENUS (saves); duels keep MATCH/BOSS. SFX: CoinsDrop, LifeGain/LifeLoss (event results), Shuffle (pack burst), Daytime (sleep).
- Boss themes (`DelveDay.bossTheme`): best of tribe (most common creature type ≥7, excluding Human) / Flyers / Removal and control / Swarm (weighted 2/3) in the boss's colours; `buildDeck(..., prefer)` picks up to 12 theme cards first (max 4 per mana value), then fills the curve. Shown in the boss prompt; dev export names files boss_i_<Theme>.dck.
- Commander access: Card Shop's 8th single is always an era legend. (Keeping a borrowed house deck on a pod win was removed at Tyler's request.)
- Tavern stakes: just for fun / gold bet (`DelveEconomy.TAVERN_BETS` 5/10/20 per opponent, max 30 total) / ante (each AI antes a random non-basic from its deck, player picks one of up to 40 collection cards, cheapest rarity first; winner takes all). 3 antes per tier (`DelveProfile.antesLeft/useAnte`, keyed to topTier).
- Gotcha: card art (RewardActor) ignores actor alpha; use the `shade.png` overlay to dim.
- Gotcha: libGDX ClickListener fires on disabled buttons; `DelveScene.button()`/`choose()` guard with isDisabled().
- Rankings (`DelveRank`): `res/draft/rankings/<set>.rnk` → score 1.0 (best pick) to 0.0, rarity fallback. Drives half-decks, upgrade rewards, enemy decks.
- Run start = Jumpstart: `DelveDay.halfDecks` makes 3 mono-colour 12-spell half-decks (rank ~0.15-0.75, up to 6 theme cards); player picks 2 → `combine` (24 spells + 16 basics, name "A + B").
- Upgrade rewards: `DelveDay.upgradeChoices(rng, deck, colors, depth)` = on-colour, not in deck, ranked above deck's weakest; bands by depth {.35-.80, .50-.92, .60-1, .72-1}; elites lead with a rare. `addOrSwap` lets the player swap out the weakest card.
- Enemy deck rank bands: EARLY ≤0.55, FIGHT ≤0.75, LATE 0.2-0.9, ELITE ≥0.3, BOSS/CASTLE best first.
- Prerelease moved to the Card Shop (`DelvePrereleaseScene`): 150g, once per day, 6 packs into collection → sealed build → 3 rounds vs a 3-person field with standings (other match simulated) → prize boosters {0,1,2,4} by wins. Per-set special rules were rejected for now (maybe a future optional run mode).
- Pai Gow (`DelvePaiGowScene`, Card Shop): Booster Blitz. Pick a tier's pack (PACK_PRICE 60g, 3 matches/day via `DelveProfile.paiGowToday/markPaiGow`); pile builder (Pick → Place here, Auto-split = top-12 by rank dealt snake-style + creature balancing); piles shuffled; up to 4 games, first to 3. `DelveDuelScene.setupPaiGow`: deck = the 3-card pile, starting hand 3, 5 life, 12 `Pai Gow Wellspring` lands (indestructible, shroud, any colour) on each battlefield, `Delve Pai Gow Rules` in command zone (skip draws from an empty library), `Power Play` (variant card DB!) for the loser of the last game, `GameRules.setMulligans(false)` (upstream edit in MulliganService). Win: pick 2 of their pack (best 2 preselected). Loss: they take your 2 best-ranked (your pack goes into the collection at purchase; `removeFromCollection`). Tie: nothing.

## Building (cloud workspace)
- Forge's `.mvn/maven.config` forces its own settings file, so the agent proxy must be passed as GLOBAL settings: `mvn -gs ~/.m2/settings.xml ...` with a `<proxies>` block pointing at the agent proxy (127.0.0.1:$PORT from $HTTPS_PROXY — the port can change between sessions).
- Build: `mvn -B -q -o -gs ~/.m2/settings.xml -DskipTests -Dcheckstyle.skip -pl forge-gui-mobile-dev -am package` → `forge-gui-mobile-dev/target/*-jar-with-dependencies.jar`.
- Smoke test: xvfb-run + xdotool; prefs `UI_SELECTOR_MODE=Adventure`, `DEV_MODE_ENABLED=true` (Dev → Win Game after keeping hand). Run with cwd `forge-gui/`. Kill with `pkill -x java` (never `pkill -f` with the jar name — it matches the shell).
- Balance sims: AI-vs-AI via forge-gui-desktop `sim`; deferred per Tyler (AI difficulty later).
